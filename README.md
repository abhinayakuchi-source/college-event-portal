# 🎉 Responsive College Event Portal

A responsive college event management website built using **HTML5, CSS3, Bootstrap 5, and JavaScript**. The portal provides event information, schedules, announcements, event registration, gallery, and contact details.

## 📖 Overview
The College Event Portal is a web-based application that helps organize and display details of college events. Students can browse upcoming events, view schedules, and get event information in a clean, responsive interface.

## ✨ Features

* 🏠 Home page with festival highlights and announcements
* 🎪 Event listings with name, date, time, venue, and description
* 📝 Event registration form with JavaScript validation
* 📅 Event schedule
* 📢 Dynamic announcements using JavaScript
* 🔍 Event filtering by category
* 🖼️ Responsive event gallery
* 📞 Contact information and contact form
* 📱 Responsive design for desktop, tablet, and mobile
* ⚡ Dynamic registration and contact success messages

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Bootstrap Icons

## 📸 Gallery

The project includes a responsive gallery section for displaying college festival and event images.

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Add event images inside the `images` folder.
4. Open `index.html` in a web browser.

No additional installation is required.
