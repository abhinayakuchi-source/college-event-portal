# 🚀 HackSphere 2026 — College Event Portal

> A responsive and interactive college event portal designed for HackSphere 2026, featuring Technical, Non-Technical, and Cultural events in one engaging digital experience.

---

## 📌 Project Overview

**HackSphere 2026** is a responsive college event portal created for **Prathyusha Engineering College**.

The portal is designed to present and organize different types of college events through a modern and engaging web interface.

HackSphere 2026 is **not limited to a hackathon**. The event portal brings together multiple categories of activities, including:

- 💻 Technical Events
- 🧠 Non-Technical Events
- 🎭 Cultural Events

The project demonstrates how HTML5, CSS3, Bootstrap 5, and JavaScript can be combined to create an interactive college-event experience.

It was developed as part of my software-development learning journey, where I applied concepts such as **semantic HTML, forms, CSS Flexbox, CSS Grid, responsive design, media queries, animations, Bootstrap components, JavaScript, DOM manipulation, arrays, functions, events, and form validation**.

---

# 🎯 Problem Statement

College events often involve multiple categories, schedules, venues, registrations, and announcements.

When this information is presented without proper organization, students may find it difficult to discover events and understand event details.

The **HackSphere 2026 College Event Portal** provides a centralized frontend interface where event information can be organized and presented in a visually engaging way.
