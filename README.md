# 🎓 HackSphere 2026 – College Event Portal

A responsive and attractive college event management website developed for **Prathyusha Engineering College**.

The portal provides information about college events, schedules, announcements, event registration, gallery and contact details.

## ✨ Features

- 🏠 Attractive Home Page
- 🎓 Prathyusha Engineering College branding
- 💻 HackSphere 2026 Hackathon
- 📢 Dynamic announcements
- 🎯 Technical, Cultural and Sports events
- 🔎 Event category filtering
- 📅 Event schedule
- 📝 Event registration form
- ✅ JavaScript form validation
- 🖼️ Responsive event gallery
- 📱 Mobile-friendly design
- 📍 Venue and contact information
- 🎨 Modern responsive UI
- ⚡ Bootstrap components and icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the `images` folder is present.
4. Open `index.html` in any web browser.
5. The website will open directly.
